אתר שתפקידו לתרגל את החומר שנלמד בתיכון בשביל שנה א׳ באוניברסיטה בכלל התארים המדעיים. 
מהווה בסיס חזק יחד עם סטוני הסבר מהיוטיוב, פתרונות מלאים, המלצות לתרגול ומעל 130 סוגי תרגילים שונים.
האתר בנוי מכמה חלקים: 
  1. תרגול שאלות אמריקאי - תרגול של שאלות עם אפשרות לבחור את נושא השאלות, שאלות שתורגלו, או רמה. אם עונים על שאלה ומקבלים שגיאה, יש אפשרות להוסיף טקסט שמסביר למה טעיתם וזה נלקח בחשבון בהמלצות.
  2. דף טעויות - דף שמרכז את כל הטעויות שנעשו בשאלות האמריקאיות ומאפשר גישה לצפייה בסרטונים הרלוונטיים ומאפשר תרגול נוסף בנושאים.
  3. דף סילבוס - מאפשר לתרגל ולסמן את הנושאי לימוד הרלוונטיים, דבר שנלקח בחשבון בדף ההמלצות. בנוסף קישורים לתרגול של הנושאים ולסרטונים בכל נושא.
  4. דף המלצות - דף שתפקידו לרכז את המלצות לתרגילים הבאים לתרגול והנושאים הבאים ללמידה, לוקח בחשבון את כמות הטעויות, נושאים שלא נלמדו, וכמות התרגול בכל נושא להמלצות.
