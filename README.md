# פשוט לתרגל — אתר תרגול מתמטיקה לקראת שנה א'

## הקבצים
- `index.html` — הדף
- `styles.css` — העיצוב
- `videos.js` — **רשימת הסרטונים. זה הקובץ שעורכים כדי להוסיף סרטונים.**
- `gens.js` — מאגר השאלות: 132 סוגי שאלות ב-12 נושאים, עם מספרים חדשים בכל פעם
- `app.js` — הלוגיקה של האתר

## העלאה ל-Netlify
1. נכנסים ל-https://app.netlify.com/drop (עם חשבון חינמי).
2. גוררים את כל התיקייה לדף.
3. מקבלים קישור ציבורי. לשינוי השם: Site configuration → Change site name.

## עדכון (למשל אחרי הוספת סרטונים)
באתר של Netlify: הפרויקט → Deploys → גוררים שוב את התיקייה. הקישור נשאר אותו קישור,
וההתקדמות של הסטודנטים לא נמחקת (היא שמורה אצלם בדפדפן).

## הוספת סרטון
ב-`videos.js`, בתוך הנושא הרצוי, מוסיפים שורה לרשימה `videos`:
